# App Review notes / 審核備註

## Paste into App Store Connect (English)

SmartFinance Max is a personal bookkeeping app for iPhone and iPad. Sign-in is not required and there is no demo account. An optional in-app PIN can be skipped. All finance entries are manual; there is no bank connection, real payment, subscription purchase, or in-app purchase.

1. Launch and tap **開始使用**. In **記帳**, tap **輸入金額**, enter `88`, tap **完成輸入**, select **餐飲**, and tap **儲存**. This is sample data, not a payment.
2. Open **總覽 → 明細** to find the entry, then **統計** to see a report for the current month.
3. Open **錢包 → 新增錢包項目 → 訂閱／定期項目 → 自訂服務** to create a test recurring item without making a purchase or providing an account.
4. Open **設定 → 通知** to see system permission and reminder settings. If testing delivery, tap **啟用 iPhone 通知** if shown, allow notifications, then tap **發送測試通知**. A local test is scheduled for approximately five seconds later. If permission is denied, **開啟 iOS 設定** goes to the app's system settings and automatic reminders can still be disabled in-app. No push token or server is required.
5. Optional: **設定 → 資料與備份 → 匯出 JSON** opens the iOS share sheet. You may cancel without changing data. The app works offline for bookkeeping; updating the public card catalog and opening external subscription-management links require a connection.

## 繁體中文速查

毋須登入或提供審核帳號；可略過 App PIN。首次啟動按「開始使用」，可用 HK$88 與「餐飲」測試記帳，再到總覽查明細及報告。錢包可建立測試定期項目，唔會實際購買服務。「設定 → 通知」可試發本機通知；唔用推播或伺服器。審核聯絡資料需由發佈者填寫。
